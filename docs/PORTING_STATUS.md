# 移植与验证状态

更新：2026-10-25。行为基准是 MikuMikuDanceE v9.32 x64；二进制身份与验证规则见 [x64 重建基准](X64_RECONSTRUCTION.md)。项目没有全库严格等价证明，也不声称取得原作者源码。

## 当前实现

- MME 作为静态库并入宿主，设备、场景和绘制边界由宿主桥接；相关模块见 [架构](ARCHITECTURE.md)。
- 应用与本地 Bullet 源码中的手写汇编和裸函数已替换或移除。x86 数值兼容仍依赖特定浮点表达式和编译选项；SSE intrinsic 不属于手写汇编。
- 帧定位已按显示、表情和骨骼轨道拆分，修复了跨数组成员写入。帧复制粘贴、全局轨道注册分别维护，PMM v2 配置恢复按阶段组织，保留原调用顺序。
- 原版 x64 复核后，修正了全局轨道第 0 帧覆盖、PMM 分组状态保存字段、PMM v2 相机参照模式恢复、x64 骨骼位置插值的单精度舍入。
- Track 渲染恢复原版的参照点分支、父骨骼旋转转置及保存的旋转基重置；模型下拉框切换后恢复主窗口焦点。
- 修复描边粗细及英文名称对话框安装编辑框回调时的 x64 地址截断；描边对话框按原版保留提交规则及分架构浮点算序。
- 两架构共用具名运行时对象，移出句柄、回调、剪贴板、选区、矩阵和设备灯光；修正面板标记清理目标、灯光 RGB 副本脱节，以及范围选择误用关键帧地址。原版依据与生命周期规则见 [架构](ARCHITECTURE.md#所有权与边界)。
- 运行时类型恢复尚未完成，仍有字节偏移、外置状态和未恢复区域。固定格式长度、资源 ID、原版字符串、数学常量和求值顺序须按其用途保留。

数值约束见 [重建基准](X64_RECONSTRUCTION.md#数值兼容)。历史修复和调查记录通过 Git 历史查阅，本页保留实现状态及已执行验证的摘要。

## 最近验证

2026-10-25，运行时状态统一及灯光、选区修正后，x64/x86 Release 完整构建与 CTest 分别为 56/56、55/55 通过，无跳过。通过 IDA MCP 定位原版指令后执行其机器码：每架构 3 组灯光方向、完整设备灯光和相机视角（每组 120 字节），以及骨骼／表情共 24 组范围坐标、Shift 与状态转换均与生产实现一致。选区回归另检查替换范围时三类模型轨道的首尾记录及无关字段；在隔离副本恢复旧的表情缓冲区地址表达式后，两架构的三个范围写入分支均失败。用户提供的 PMX 在两架构完成共 20 轮描边对话框操作及英文名称对话框回归；粗细 0、0.5、1、2 的 GPU 顶点缓冲检查确认全部 139,692 个描边顶点响应变化，主体缓冲保持一致。这些结果覆盖本轮改动，不代表完整 GUI、PMM 工程往返和全程序严格等价已获证明。

2026-10-25，描边对话框修复（`900c066`）后本地 x64/x86 Release 完整构建与 CTest 分别为 55/55、54/54 通过，无跳过。原版 x64 机器码在指令仿真及原生 Win32 控件桥接下执行，与生产实现的 14 个状态快照一致；用户提供的 PMX 在两架构完成共 20 轮对话框操作及英文名称对话框回归。[自动化回归](../tests/edge_thickness_dialog_test.cpp)覆盖窗口过程、数值及窗口生命周期；完整应用的菜单点击和逐像素图像对照尚未完成。

测试数量与环境可能随版本变化。复现构建和测试使用 [发布说明](RELEASES.md#reproduce-the-release-build)；D3D9 曾在部分会话状态下不可用，设备创建失败和跳过结果按各次实际运行保留。

同日 Track/模型切换修正后，本地 x64/x86 Release 完整构建完成。新增相机矩阵回归覆盖 19 个场景，修复前两架构均失败，修复后均通过。与原版 x64 机器码对照的七个固定场景，最终 World×View 差值均为 0。完整 CTest 为 x64 42 通过/9 跳过/1 失败（52 项）、x86 41 通过/9 跳过/1 失败（51 项）；失败仍为 `mme_d3dx_runtime` 的原生设备创建错误 `0x8876086C`，9 项因设备不可用跳过。矩阵专项不依赖 GPU，未代替完整 GUI/图像对照。
